# 设计摘要

本摘要记录 llama-CPP 对 llama.cpp CPU 后端的关键优化方案。完整详细设计文档（含算法细节、接口与数据打包配图）保存在原始目录 `~/llamacpp优化设计文档/llamacpp_鲲鹏920B优化_详设文档_v1.0.md`，不随本仓库分发。

## 总体架构

优化不修改上层 API 与计算图结构，在 GGML CPU Backend 中通过 `type_traits` 回调注册机制替换底层 kernel：

| 层次 | 优化状态 | 关键组件 |
| --- | --- | --- |
| 应用层 | 未修改 | llama-embedding / llama-bench / llama-server |
| 框架层 | 部分修改 | GGML OP IR（新增 GGML_OP_FUSED_CPP_SDPA_EXT）→ type_traits matmul 路由 + fused SDPA 分发 |
| Kernel 层 | 全部新增 | FP16/FP32/Q8_0 MatMul + Fused SDPA（NEON/SVE/i8mm） |
| 硬件层 | 未修改 | NEON、SVE-256 (256-bit)、i8mm；OpenMP 并行；64B 对齐 |

## FP16 矩阵乘法（MATMUL）

Embedding 权重为 F16 时矩阵乘法集中在 prefill 阶段，提供四层 kernel：

- `vec_dot_f16`：NEON 软件流水线点积（8 个 float16x8 累加器，64 元素步长），通用兜底；
- `matmul_f16_4x4_kernel`：NEON 外积 4×4 tile（16 次 vfmaq_f16，fp16×fp16→fp32），prefill 小批量（M<16）；
- `matmul_outer_8x16_b_micro_packA_f16`：手写 NEON 外积 8×16 tile + packA 预打包，K 按 32 双缓冲，prefill 大批量（M>=16，约束 M%16==0、N%8==0）。

源码：`ggml/src/ggml-cpu/vec.cpp` / `vec.h`。

## FP32 矩阵乘法

SVE 4×4 tile kernel：256-bit SVE 8-lane FP32，16 个 svfloat32 累加器，K 按向量长度分块，16 次 svmla 后水平求和；尾循环回退 `ggml_vec_dot_f32`。源码：`vec.cpp` / `vec.h`。

## Q8_0 量化矩阵乘法（MMLA + Spack）

性能提升最大的模块：

- 将 `block_q8_0` 数据按 MMLA（i8mm smmla）指令所需内存布局重新打包（spack）；
- micro-kernel 用 SMMLA 计算 int8 点积得 int32，再乘 A/B scale 累加进 FP32；
- 分块：Outer tile M=128 × N=64，K tile=2048，Micro tile 8×8；A 按 2 行/组、B 按 4 行/组打包，A panel 跨 N tile 复用；
- `type_traits[GGML_TYPE_Q8_0]` 注册 `matmul_q8_0_mmla_spack_b_g`，非对齐回退通用 kernel。

源码：`ggml/src/ggml-cpu/ggml-cpu-quants.c/.h`，路由在 `ggml-cpu.c`。

## Fused SDPA（FlashAttention v2 NEON）

把 QKᵀ、scale、mask、softmax、PV 从多个算子融合为单一 CPU kernel，按 tile 流式计算，减少中间张量与内存流量。

- 编译宏：`GGML_USE_FUSED_CPP_SDPA`；
- 启用条件（`llama-graph.cpp` 的 `build_attn_mha()`）：ARM64、q/k/v 均 F32、MHA（n_head==n_head_kv）、无 MLA/ALiBi/attn_soft_cap、mask 为 F16/F32 contiguous 或无 mask、v->ne[0]%8==0；
- 对角分块：L==S 且 L%64==0 时按 64×64 对角块只计算因果上三角；
- NEON kernel：Q/K/V 微内核内 pack+transpose，L3-cache-aware KV 分块，fp32 内部精度、pb16 近似 softmax，提供 mask_f16/mask_f32/无 mask 变体，按 head 分区并行。

源码：`ggml/src/ggml-cpu/fused-cpp/fp32_packqkv/`、入口在 `ops.cpp`，op 定义在 `ggml.h`/`ggml.c`。

## 编译

```bash
./compile.sh build-delivery     # 默认：-O3 RelWithDebInfo（ggml-cpu / llama-embedding / llama-bench / llama-server）
./compile.sh build-fused-sdpa   # ARM：-march=armv8.6-a+dotprod+i8mm+sve -O3 -funroll-loops
```

环境变量 `GGML_FUSED_CPP_SDPA` 控制 fused SDPA 启停（`0`/`off`/`false`/`no` 关闭，`debug`/`trace` 开启调试日志，其他默认启用）。
